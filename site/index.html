Skate

A small Scheme compiler for Z80 computers running CP/M.

Run Skate 0.5.1 in your browser

No installation is needed. The system boots directly into CP/M. Type B: to use your writable work disk, then RECEIPT, ROUTE or ACCOUNT.

Keep the resulting browser URL to reopen the same work disk. Download a backup before clearing browser storage.
